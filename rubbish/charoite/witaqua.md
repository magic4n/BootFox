📱 Installation Guide / Инструкция по установке
🇬🇧 English
⚙️ How to install:
🔧 Flash the firmware 3.0.304 Global
🔄 Reboot to FastbootD:
fastboot reboot fastboot
💾 Flash system:
fastboot flash system alpha.img
🐧 Linux:
fastboot flash alpha.img
🔓 (Optional) Erase FRP:
fastboot erase frp
🚀 Reboot:
fastboot reboot
✅ Done!
TIP: you can flash boot with Magisk or APatch and install "charoite_fixes_v2.zip" for fix brightness.
🇷🇺 Русский
⚙️ Как установить:
🔧 Прошейте прошивку 3.0.304 Global
🔄 Перезагрузитесь в FastbootD:
fastboot reboot fastboot
💾 Прошейте system:
fastboot flash system alpha.img
🐧 Linux:
fastboot flash system alpha.img
🔓 (Опционально) Сотрите FRP:
fastboot erase frp
🚀 Перезагрузитесь:

✅ Готово!
